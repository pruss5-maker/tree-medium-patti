# Build the Tree Medium Brand

Create clear, warm, grounded work for Psychic Sister Pat while preserving the distinctive Tree Medium idea and the user's own voice.

## Start Every Task

1. Read [references/brand-foundation.md](references/brand-foundation.md) completely.
2. Inspect the existing project before changing website files. Preserve deliberate user changes and follow the project's established stack and style.
3. Treat `/home/koreypatti/image_content_references` as the `icr` folder for Tree Medium reference images. Recheck it whenever the user mentions an image, screenshot, visual reference, or social-media example.
4. Verify exact social handles or URLs before attributing any public account to Psychic Sister Pat. If no exact match is available, use supplied screenshots or ask for the handle instead of guessing.

## Shape the Work

- Lead with the audience's desired feeling: calmer, grounded, protected, reassured, and able to reflect clearly.
- Explain the offer in plain language before using spiritual vocabulary.
- Keep the Tree Medium concept central rather than reducing the brand to generic psychic services.
- Use nature imagery purposefully: roots for grounding, canopy for perspective, bark for protection, seasons for change, and groves for community.
- Make calls to action gentle but direct, such as `Book a Tree Message` or `Enter the Grove`.
- Distinguish confirmed facts from working ideas. Label proposed names, prices, packages, testimonials, credentials, and policies as drafts until the user approves them.

## Write in Sister Pat's Voice

- Sound warm, earthy, sisterly, reassuring, intuitive, protective, and lightly playful.
- Prefer short, memorable language over ornate mystical prose.
- Balance wonder with clarity. Let the woo feel welcoming rather than intimidating.
- Use the sanctuary-versus-battlefield idea as a signature theme, not a repeated slogan on every section.
- Preserve the user's phrasing when it has personality; polish spelling and structure without making the voice corporate.

## Build Website Experiences

Prioritize this visitor journey:

1. Understand who Sister Pat is and what a Tree Medium does.
2. Recognize the emotional benefit and whether the experience feels right for them.
3. See the available services and what to expect.
4. Find trust signals, boundaries, and frequently asked questions.
5. Take one obvious booking or contact action.

Use a simple initial information architecture: Home, About, Services, What to Expect, FAQ, and Book or Contact. Add pages only when real content justifies them. Design for mobile use, accessible contrast, readable type, keyboard navigation, useful alternative text, and reduced-motion preferences.

## Review and Create Social Content

When reviewing existing social media:

1. Confirm the account belongs to the user.
2. Examine repeated topics, opening hooks, visual motifs, tone, calls to action, audience questions, and engagement patterns.
3. Separate observed evidence from recommendations.
4. Preserve recognizable strengths while identifying gaps in clarity, consistency, and conversion.

Organize new content around the five pillars in the brand foundation. Mix reassurance, education, storytelling, participation, and offers rather than posting only promotions.

## Keep Claims Responsible

- Present readings and spiritual practices as guidance, reflection, and personal experience.
- Do not promise guaranteed predictions, healing, protection from harm, or specific outcomes.
- Do not frame spiritual services as a substitute for medical, mental-health, legal, financial, or emergency support.
- Avoid diagnosing people or intensifying fear, paranoia, or dependency.
- Use a concise spiritual-services disclaimer where the context, platform, or local rules call for one; do not let disclaimers overwhelm the brand voice.

## Deliver Finished Work

- Provide usable copy, content, or implementation rather than only abstract strategy when the user asks to create something.
- Keep placeholders visibly labeled.
- Check names, links, mobile layout, accessibility, and claims before handing off website changes.
- State which material came from supplied references and which parts are recommendations.
